## Implementation

- `app/pages/lab/index.astro`, `app/components/LabItem.astro`, `app/styles/lab-index.css`, and `app/lib/lab-index.js` reproduce the source's 36 entries, List/Wheel/Grid views, persistence, previews, reel selection, responsive and lifecycle behavior. The original index runtime is reused with its mesh import adapted to the established shared runtime.
- `app/pages/lab/[slug].astro`, `app/components/LabDocument.astro`, and `app/styles/lab-detail.css` provide all nine static routes with the same shared shell, empty stage, Docs toggle, Notes/Code panes, scrollbar, Tune shell and cyclic persisted navigation. The old Phase 1 `/lab/dial` placeholder was removed in favor of this common route.
- `app/lib/lab-doc.js` adapts the original shared document and configurator runtime. `registerLabExperiment` starts empty and permits future modules to register the original async mount/config contract. It handles cleanup, aborted or failed loads, and mounted instance methods; no Phase 8 module is imported. `app/lib/runtime.ts` registers only the shared Lab index/document engines with the existing lifecycle.
- The captured Dial and Vocal Orb panes and their metadata/JSON-LD are retained. The seven uncaptured articles remain empty. For those seven pages, the known title/canonical/poster are used, with existing site-wide description and Lab OG/JSON-LD fallbacks rather than invented page-specific claims. Their original page-specific metadata remains unknown.
- The original scoped styles explicitly gave the hidden Tune button a display value, which made it visible without a registered config. The reconstruction respects `hidden`. The original reduced-motion rule also left the stage over open docs; the reconstruction retains the normal open-docs end position without animating it. Persisted navigation updates its screen-reader labels along with its links and odometer.

## Remaining limitations

1. The nine experiment engines are intentionally absent. Seven Notes/Code articles and their specific descriptions/metadata are not captured; no substitute content was invented.
2. Original Lab posters, reels, fonts and OG files are not present in `app/public`. Their original URLs remain in the implementation. This sandbox cannot establish their real availability, appearance, CORS or video playback; all visual comparisons deliberately blocked remote media. Font fallbacks may alter real-site text metrics.
3. The live original was not browser-inspected; the visual comparison used the saved original HTML/CSS/JS routed locally. A final Chromium audit compared the saved original, a separate Phase 6 baseline build and the Phase 7 build at 1440×900 and 375×812 with remote media blocked. Nine header elements had identical measured geometry/display/font size between baseline and Phase 7; their header markup was also identical on all nine baseline routes. The original reference differs: its bell SVG measures 18×18 px versus 38×38 px in both baseline and Phase 7, and its mobile command control is hidden while the baseline/Phase 7 control remains visible over the logo. These are inherited shared-chrome differences, not Phase 7 regressions, so the chrome was not changed. The existing global chrome also contains duplicate SVG IDs; this phase avoids adding further duplicates but does not refactor the shared chrome.
4. The four shared feed/sitemap resource paths above remain missing in this static build. Backend/API gaps and other prior-phase limitations are unchanged.
5. `npm ci` used the existing lockfile without changing dependencies and reported three existing audit findings (one low, one high, one critical). Temporary browser/test packages were installed outside the repository only.
